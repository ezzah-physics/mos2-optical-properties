# Layer-Dependent Optical Properties of MoS₂: A Literature-Based Data Analysis

**Author:** Ezzah Shahid
**Field:** Nanophysics and Nanotechnology
**Tools:** Python (pandas, matplotlib), Google Colab, WebPlotDigitizer
**Research work supervised by:** Dr. Syed Shahbaz Ali

## About

MoS₂ is a layered semiconductor whose optical properties depend strongly on the number of atomic layers. This project collects **experimental values reported in published papers** and compares the optical band gap and photoluminescence (PL) of monolayer, bilayer and multilayer MoS₂.

> **Important:** this is a literature-based analysis. No measurement was done by the author, and no value was estimated or calculated and then presented as a measurement. Values for 3–6 layers exist only in a figure of the source paper and were digitised (labelled `digitised from Fig. 3(c)`, uncertainty ≈ ±0.02 eV, the author's own estimate).

**Research question:** How does the number of atomic layers influence the optical band gap and photoluminescence behaviour of MoS₂?

## Main findings

- Monolayer: direct gap at about **1.82–1.90 eV**, with much stronger PL than thicker samples.
- Two or more layers: the lowest transition is **indirect** (1.59 eV for 2 layers) and decreases toward the bulk value as layers are added.
- PL quantum yield (Mak et al.): up to 4×10⁻³ for the monolayer vs. about 10⁻⁵–10⁻⁶ for 2–6 layers.
- Differences between papers are explained by substrate, doping, sample type and measurement method.

## Data sources

2. N. Scheuschner et al., *Photoluminescence of freestanding single- and few-layer MoS₂*, Phys. Rev. B **89**, 125406 (2014). doi:10.1103/PhysRevB.89.125406
3. W. Li et al., *Broadband optical properties of large-area monolayer CVD molybdenum disulfide*, Phys. Rev. B **90**, 195434 (2014). doi:10.1103/PhysRevB.90.195434
4. W. Jin et al., *Direct measurement of the thickness-dependent electronic band structure of MoS₂ using ARPES*, Phys. Rev. Lett. **111**, 106801 (2013). doi:10.1103/PhysRevLett.111.106801 (used only to support interpretation, not as optical data)

## Limitations

- Values for 3–6 layers are digitised from one figure (≈ ±0.02 eV, author's estimate).
- Papers differ in sample type, substrate, temperature and method, so the comparison is qualitative to semi-quantitative.
- Only three primary experimental papers were used.
- Mak et al. state the quantum-yield enhancement differently in the preprint and the journal abstract; only the preprint text values are used here and should be checked against the published paper.
- All energies are optical (exciton-dominated) energies, not electronic (quasiparticle) gaps.
